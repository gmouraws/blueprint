# Language rules

Blueprint Room's user-facing interface is exclusively Brazilian Portuguese. Code identifiers, code comments, tests and repository documentation are English. Keep product/platform names (Blueprint Room, LiveKit, Vercel, Chrome, Edge) unchanged. Use natural Portuguese labels for controls, errors and permissions.

There is no /pt route tree, language switcher, MDX registry or translation-revision workflow in this application. These belonged to the previous website and are recoverable from Git history. Do not translate browser-owned capture/device pickers, whose language follows the browser/OS.
