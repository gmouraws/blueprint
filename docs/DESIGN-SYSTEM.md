# Blueprint Room presentation

A restrained dark shared space with a small three-bar room mark, clear text and mint accents. No copied Discord branding, fictitious participants, decorative landing sections, animation or gradients.

Tokens: background #10151b, surface #181f28, text #edf1f5, muted #a6b2c1, accent #a3e1c5, dividers #303b48. System sans-serif for reading; monospace only for small labels. Controls have at least 44px height, visible focus and explicit labels. Status is textual as well as colored.

Entry: one compact, centered nickname/password card with the direct title "Entrar na sala" and the room capacity and capabilities below it. Preserve the brand/private-space header, dark palette and existing form treatment. No slogans, promotional column or repeated branding. Permission guidance stays beside the entry action. Invalid configuration disables entry and provides expandable diagnostics containing only variable names and safe status categories. Room: participants on the left, screen viewer in the center, ephemeral chat on the right, call controls below. The viewer grows with the available space. Below 900px chat stacks beneath the viewer; small screens stack the participants too. Long nicknames/messages wrap. No horizontal page overflow at 320px.

The old Technical Editorial website is retained only in Git history. Its mark, navigation, biographies, articles and marketing assets are no longer served.
